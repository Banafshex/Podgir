# پادگیر · Podgir

یک پخش‌کنندهٔ پادکست اندرویدی، بدون حساب کاربری و بدون سرور اختصاصی. رابط برنامه فارسی (راست‌به‌چپ) و انگلیسی و دارای حالت شب و روز است.

## امکانات نسخهٔ اولیه

- کشف و جست‌وجوی پادکست با API جست‌وجوی عمومی iTunes / Apple Podcasts، با پیشنهادهای جست‌وجوی فارسی؛ همچنین باز کردن آدرس HTTPS فید RSS از کادر جست‌وجو
- دنبال‌کردن پادکست‌ها و نگهداری فهرست‌ها و محل پخش به صورت محلی
- پخش پس‌زمینه با Media3، کنترل از اعلان، پرش ۱۵ ثانیه به عقب و ۳۰ ثانیه به جلو، تغییر سرعت و تایمر خواب در پنل پخش (برای باز کردن پنل روی نوار پخش بزنید)
- دانلود توسط DownloadManager اندروید، پخش فایل دانلودشده و حذف دانلود از کتابخانه
- انتخاب زبان و پوسته و آیکون مینیمال

جست‌وجو و فیدها به اینترنت و دسترس‌پذیری سرویس‌های مربوطه بستگی دارند؛ نتایج اپل لزوماً جامع نیستند. فقط آدرس‌های HTTPS پشتیبانی می‌شوند. دانلودها و اطلاعات محلی با حذف برنامه پاک می‌شوند و بین دستگاه‌ها همگام نمی‌شوند. تایمر خواب تا زمان فعال بودن برنامه کار می‌کند. این نسخهٔ اولیه هنوز قابلیت‌هایی مانند صف پخش، دریافت خودکار قسمت‌های جدید، وارد/خارج‌کردن OPML را ندارد.

## ساخت

Android Studio با JDK 17 و Android SDK 35 نیاز است. پروژه را باز کنید و اجازه دهید Gradle وابستگی‌ها را دریافت کند، یا اجرا کنید:

```sh
./gradlew assembleDebug
```

APK در `app/build/outputs/apk/debug/` قرار می‌گیرد. برای ساخت اولیه باید به مخازن Google Maven، Maven Central و Gradle دسترسی داشته باشید.
