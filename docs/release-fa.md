# انتشار رسمی پادگیر ۱٫۰٫۰

## اصل امنیتی

فایل کلید امضای انتشار، گذرواژه‌ها و نام کلید را **در گفتگو یا Git قرار ندهید**. کلید انتشار را در جای امن و همراه با نسخهٔ پشتیبان نگه دارید؛ GitHub پس از ثبت Secret محتوای آن را دوباره نمایش نمی‌دهد. از کلید یک‌بارمصرف، کلید دیباگ یا کلید عمومی برای انتشار واقعی استفاده نکنید. گم‌شدن کلید ممکن است به‌روزرسانی نسخه‌های نصب‌شده را ناممکن کند.

## آماده‌سازی کلید توسط مالک

در Android Studio از بخش **Build → Generate Signed Bundle / APK** یک keystore جدید و یک کلید انتشار بسازید، یا از کلید انتشار موجود خود استفاده کنید. فایل و گذرواژه‌هایش را خارج از مخزن در محل امن و پشتیبان نگهداری کنید. اگر قبلاً پادگیر را با کلید دیگری منتشر کرده‌اید، برای سازگاری نصب به همان کلید قبلی نیاز دارید.

در تنظیمات مخزن GitHub، بخش **Settings → Secrets and variables → Actions → New repository secret**، چهار Secret زیر را مستقیماً ثبت کنید (مقدارشان را در چت نفرستید):

- `ANDROID_KEYSTORE_BASE64`: محتوای باینری فایل keystore به صورت Base64 بدون شکستن خط. در ترمینال لینوکس می‌توانید با `base64 -w 0 /path/to/keystore` مقدار آن را بسازید؛ خروجی را فقط در کادر Secret وارد کنید.
- `ANDROID_KEYSTORE_PASSWORD`: گذرواژهٔ keystore.
- `ANDROID_KEY_ALIAS`: نام کلید داخل keystore.
- `ANDROID_KEY_PASSWORD`: گذرواژهٔ همان کلید.

در تنظیمات Actions اجازهٔ ایجاد و نوشتن release توسط `GITHUB_TOKEN` لازم است. هیچ‌کدام از اطلاعات امضا وارد کد یا فایل‌های Git نمی‌شوند. نسخهٔ ۱٫۰٫۰ دارای `versionCode` برابر ۱ است.

## اجرای انتشار

پس از تنظیم Secretها، workflow **Android build** را از شاخهٔ `arena/1d50521a-podgir` با گزینهٔ `publish` اجرا کنید. ابتدا تست‌ها و بیلد دیباگ و سپس ساخت آزمایشی با کلید موقت انجام می‌شود؛ کار انتشار جداگانه، با کلید مالک APK نسخهٔ release را می‌سازد، امضایش را با `apksigner` بررسی می‌کند و فقط در صورت موفقیت GitHub Release و فایل `Podgir-1.0.0.apk` را منتشر می‌کند. اثرانگشت SHA-256 گواهی در توضیحات انتشار درج می‌شود. اگر هر Secret موجود نباشد یا امضا معتبر نباشد، انتشار متوقف می‌شود.

نسخهٔ release باید پیش از توزیع گسترده روی دستگاه واقعی تست شود. APKهای قبلی با کلید دیباگ امضا شده‌اند؛ ممکن است نصب روی آن‌ها ممکن نباشد. پیش از حذف نسخهٔ قبلی با قابلیت پشتیبان‌گیری محلی، از اطلاعات کاربر نسخهٔ پشتیبان بگیرید.
